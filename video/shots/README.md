# Studio Pro screenshots

Frames that can only be photographed, not captured from a running app: the
view entity editor, the page editor, and the widget dialogs. Everything else
in the films comes out of the app or the database.

Drop PNGs here, full window, 100% zoom, dark theme. Name them for what they
show — `viewentity-editor.png`, `page-datagrid-datasource.png`,
`column-filter-widget.png` — and the deck picks them up by that name.

They are the only light-on-dark-or-not-our-palette imagery the films carry, so
each one is framed as evidence: an inset panel with a caption naming the
version and what is being looked at, never upscaled past its own pixel size.
